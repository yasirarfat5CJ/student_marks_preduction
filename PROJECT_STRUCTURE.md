# Project Structure

## Root

- `app.py`: runs the ML training and reporting pipeline.
- `api.py`: starts the FastAPI backend.
- `dataset.csv`: source dataset used by the ML pipeline.
- `.env`: local backend configuration. Do not commit this file.
- `.env.example`: safe sample configuration.

## ML Pipeline

- `ml_pipeline/config.py`: dataset columns, paths, model settings.
- `ml_pipeline/preprocessing.py`: data validation, cleaning, outlier handling.
- `ml_pipeline/models.py`: model training and hyperparameter tuning.
- `ml_pipeline/evaluation.py`: MAE, MSE, RMSE, R2, cross-validation, feature importance.
- `ml_pipeline/prediction.py`: prediction helper for the saved model.
- `ml_pipeline/reporting.py`: final report generation.
- `ml_pipeline/visualization.py`: EDA and result plots.

## Backend

- `backend/app/main.py`: FastAPI app setup.
- `backend/app/core`: config, database connection, password hashing, JWT.
- `backend/app/models`: SQLAlchemy database tables.
- `backend/app/schemas`: request and response validation models.
- `backend/app/routers`: API routes for auth, students, predictions, what-if, admin.
- `backend/app/services`: business logic for auth, recommendations, predictions.
- `backend/app/dependencies`: login and admin authorization checks.
- `backend/scripts/create_admin.py`: create or update an admin login.

## Database

- MySQL data is stored in the `student_prediction` database.
- `backend/migrations`: Alembic migration files for database schema changes.

## Frontend

- `frontend/src`: React application code.
- `frontend/src/pages`: page-level screens such as login, register, dashboard, analytics, admin.
- `frontend/src/components`: reusable UI components.
- `frontend/src/services`: API calls to the backend.
- `frontend/src/utils/auth.js`: token and user-role helpers.

## Outputs

- `artifacts/final_model.pkl`: saved ML pipeline used by backend predictions.
- `artifacts/final_report.md`: final model report.
- `artifacts/*.csv`: model comparison and analysis tables.
- `artifacts/plots`: charts generated by the ML pipeline.

## Tests

- `tests`: backend tests for authentication, authorization, prediction history, and admin access.
